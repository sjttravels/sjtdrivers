# SJT DRIVERS • Driver Operating System & Chauffeur App

Official Driver Portal for **SJT Tours & Travels Pvt. Ltd.** (Bengaluru, Karnataka).

---

## 🌟 Included Portals

1. **Driver Website Portal** (`DriverWebsite.tsx`):
   - Real-time ride dispatch queue.
   - 1-click ride acceptance with passenger details and quoted fare.
   - 4-digit ride OTP passenger verification before trip start.
   - Odometer KM logging (start & ending KM).
   - Cash / UPI driver direct collection recording.
   - Corporate company duty shifts.
2. **Driver Mobile App (16 Slides)** (`DriverPortal.tsx`):
   - Interactive smartphone simulation for yellow-board drivers.
   - PSV badge and driver KYC document upload.
   - Accessible via the top experience toggle or directly via `/app` or `#app`.

---

## 🚀 Instant Vercel Deployment

1. Import this repository (`sjttravels/sjtdrivers`) into Vercel.
2. Vercel automatically detects Vite settings:
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
3. Click **Deploy**.
